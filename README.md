# Career Advisor AI

A machine-learning based career recommendation web app that matches a student's academic profile, skills and learning indicators to suitable technology careers.

## What changed

The original project accepted only a small set of inputs and returned one career. The new version turns it into a complete assessment tool:

- Random Forest career classifier
- 25 profile and skill features
- Data cleaning and validation before training
- Stratified train/test evaluation
- Top-5 career ranking with model probabilities
- Career-specific skill suggestions
- Step-by-step learning roadmap
- Flask web application
- JSON prediction API
- Health-check endpoint
- Automated tests
- Automatic model training when the new model file is missing

## Machine learning pipeline

The dataset contains 25 input variables covering academic performance, projects, technical ability, problem solving, programming, design, learning style and college activity. `ROLE` is the target.

The training script:

1. Loads `career_pred.csv`.
2. Removes empty career labels.
3. Cleans column names and converts feature values to numeric values.
4. Uses an 80/20 stratified train/test split.
5. Trains a Random Forest classifier with balanced class weights.
6. Reports test accuracy and a classification report.
7. Saves the trained model and label encoder to `career_model.joblib`.

## New user-facing tools

### 1. Career ranking

Instead of returning only one class, the app returns up to five career matches ordered by model probability.

### 2. Skill guide

Each supported career has a short list of practical skills to learn.

### 3. Learning roadmap

The result page gives a five-step progression from fundamentals to portfolio/application preparation.

### 4. API

`GET /health` returns the service status.

`GET /api/careers` returns the built-in career information.

`POST /predict` accepts the 25 assessment fields and returns the recommendation, ranking, skills and roadmap.

## Run locally

### 1. Create an environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model

```bash
python career.py
```

Expected output format:

```text
Rows used: <dataset rows after cleaning>
Number of careers: <number of target classes>
Test accuracy: <measured accuracy>

Classification report:
...
Saved model to career_model.joblib
```

The exact accuracy is intentionally not hard-coded in this README; it should be produced by the current dataset and installed scikit-learn version when you run the pipeline.

### 4. Start the web app

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.

If `career_model.joblib` does not exist, the app automatically trains the model on first prediction.

### 5. Run tests

```bash
pytest -q
```

## Important limitation

This is a career guidance project, not a professional career assessment. The model learns patterns from the supplied dataset, so predictions can be affected by dataset quality, class imbalance and limited feature coverage. A probability is a model confidence signal, not a guarantee that a career is suitable.
